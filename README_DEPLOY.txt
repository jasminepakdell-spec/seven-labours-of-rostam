OPTIONAL: TEST ON YOUR COMPUTER

1. Open Terminal in the folder containing the files.
2. Install Streamlit:
   pip install streamlit

3. Run the game:
   streamlit run streamlit_app.py

4. Your browser should open the local game.


PUBLISH WITH STREAMLIT COMMUNITY CLOUD

1. Create a GitHub account if you do not already have one.
2. Create a new GitHub repository.
3. Upload:
   - streamlit_app.py
   - requirements.txt
   - every GIF and image listed above

4. Go to:
   https://share.streamlit.io

5. Sign in with GitHub.

6. Click "Create app."

7. Choose "Yup, I have an app."

8. Select your GitHub repository.

9. For the entrypoint file, choose:
   streamlit_app.py

10. Choose an available app URL/subdomain.

11. Deploy.

12. Streamlit gives you a shareable URL ending in:
    .streamlit.app

IMPORTANT:
- Keep the capitalization and spelling of every image filename exactly the same.
- The images/GIFs need to be uploaded to the same repository as streamlit_app.py.
- If the app shows "Missing image file", compare that filename with the one in GitHub.
